# Making the Map

## Creating the Homestead Dataset

Our homestead parcel data set was created using data provided by the Bureau of Land Mangement's General Land Office (GLO) records [database](https://glorecords.blm.gov/search/default.aspx). While the GLO database lists the amount of data it has, it does not compare this amount to the total amount of homesteads. This means that we had to calculate the missing homesteads using numbers provided by [Homestead National Park](https://www.nps.gov/home/learn/historyculture/homesteading-by-the-state.htm)—which shows there are homesteads missing from the GLO database.

There is no easy way to access bulk data from the GLO database. Instead, we had to create a python script to scrape data off the website. You are able to download the script [here](data/parcel_processor.py). The script allows you to download data from the GLO database for any title transfer authority, not just the Homestead Act, and for any state. The script has three options:

- State — A 2-letter state postal code (i.e. WI for Wisconsin). In our case, we ran the script three times, once for each of Michigan (MI), Minnesota (MN), and Wisconsin (WI)
- Title Transfer Authority — a 6-digit code specifying the legistlation or authority under which the parcel was titled. The Homestead Act's code is 251101. A list of other codes can be found [here](https://glorecords.blm.gov/reference/default.aspx#id=05_Appendices|03_Title_Transfer_Authorities).
- Level of Detail (1,2,3) — Specifies how much detail the scraper is going to use. The GLO website limits the amount of search results for a given geograph to 900. 1 = Highly detailed. For use if you are searching for an authority with many parcels. 2 = County level. For use if you are searching for an authority with less than 900 parcels per county. 3 = State Level. For use if you are searching for an authority with less than 900 parcels in the whole state. We chose 1.

The script will output two .csv files:
- [selected state]_parcels.csv: Contains every record scraped from the GLO database. Each line in the .csv is a single record
- [selected state]_parcels_edited.csv: Splits each records scraped from the GLO database into individual parcel segments (aliquots). This file is able to be joined with a GIS file

With the [selected state]_parcels_edited.csv, you are able to join the generated parcel dataset with our prepared spatial data. The PLSS intersected dataset is the most comprehensive PLSS dataset, though it varies greatly from state-to-state. Michigan, Minnesota, and Wisconsin have good, comprehensive coverage.

Our [plss_mi_mn_wi](data/mapping_dispossession_upper_midwest.gpkg) dataset contains a few extra fields to increase ease of joining to the csv file generated by the web scraper. The field loc_code, is present in both files. If you want to join PLSS data from another state, you will need to prepare an appropriate join field.

Once we joined our csv with the PLSS GIS data, we dissolved the file based on the document number, meaning there is a single area for each record.

## Creating the Treaties Dataset

The treaty dataset is a modified version of the Royce Report, a 1890s report that described treaty-defined reservations and cessions using PLSS language. The Royce report has been digitized. However, the digitized data make no disctinction between the type of land included in the dataset. Specifically, if the land is ceded, a reservation, or if the land was at one time a reservation, and later ceded. These data were added through careful consulation of the original Royce report.

To account for these nuances, three fields have been added:

- type: whether the land was a cession or a reservation.
- e_date: the date in which the land was ceded. In the case of reservation land that remains governed by tribal nations to this day, this date is 2019.
- s_date: the date in which particular land went into Tribal control. Typically, this number is most relevant for reservations which were later ceded. For large inital cessions, this number is 0, reflecting that prior the cession, the land existed outside a Western framework of land ownership.

## Download our Data

Our geospatial data can be [downloaded](data/mapping_dispossession_upper_midwest.gpkg) as a Geopackage, which includes the following layers (see description of how layers were made in the previous section):

- mi_homesteads_aggregated: Homestead parcels for Michigan.
- mn_homesteads_aggregated: Homestead parcels for Minnesota.
- umw_land_treaties: Treaty and reservation boundaries for the upper midwest (umw).
- umw_native_homesteads_aggregated: Native Homestead parcels for the upper midwest.
- umw_native_population_2020: Native population by county in 2020.
- umw_dawes_parceps: Parcels allotted through the Dawes Act.
- wi_homesteads_aggregated: Homestead parcels for Wisconsin.
